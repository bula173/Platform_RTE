Cast Module - User Guide\n *\n * @section overview What is the Cast Module?\n *\n * The Cast module provides <strong>checked type conversions</strong> to prevent silent truncation\n * and overflow. Instead of C-style casts (which truncate silently), these functions\n * detect out-of-range values and return status codes.\n *\n * <strong>Key idea:</strong> Know when data is lost. Silent truncation is a security hole.\n *\n * @section quick_start Quick Start\n *\n * <tt>c\\n * \#include \\"safeapi/cast/sapi_cast.h\\"\\n *\\n * // ✗ BAD: Silent truncation\\n * int32_t large = 100000;\\n * int16_t small = (int16_t)large; // 100000 % 65536 = 34464 (wrong!)\\n *\\n * // ✓ GOOD: Checked conversion\\n * int32_t large = 100000;\\n * int16_t small;\\n * sapi_status_t rc = sapi_cast_int32_to_int16(large, \&small);\\n * if (rc == SAPI_STATUS_INVALID_PARAM) {\\n * log_error(\\"Value %d too large for int16_t\\", large);\\n * return rc;\\n * }\\n * // small is guaranteed in range\\n *</tt>\n *\n * @section conversions Available Conversions\n *\n * <strong>Upcasting (safe):</strong>\n * - int8 → int16, int32, int64\n * - uint8 → uint16, uint32, uint64\n * - int16 → int32, int64\n * - uint16 → uint32, uint64\n * - etc.\n * - Always safe (no overflow possible)\n\n * <strong>Downcasting (checked):</strong>\n * - int32 → int16, int8\n * - uint32 → uint16, uint8\n * - Returns INVALID_PARAM if out of range\n * - Value only modified if success\n *\n * <strong>Signed to Unsigned:</strong>\n * - int32 → uint32 (negative → error)\n * - int8 → uint8 (negative → error)\n * - Zero and positive values OK\n *\n * <strong>Floating Point (if supported):</strong>\n * - float → int32 (checks for infinity, NaN)\n * - double → float (checks for overflow)\n * - Non-finite values return error\n *\n * @section examples Practical Examples\n *\n * ### Example 1: ADC Reading Conversion\n *\n * <tt>c\\n * uint16_t adc_raw = read_adc(); // 0-4095 (12-bit ADC)\\n *\\n * // Need to convert to temperature in 0.1°C units\\n * // Safe conversion (raw fits in uint16_t)\\n * int16_t temp_units;\\n * sapi_status_t rc = sapi_cast_uint16_to_int16(adc_raw, \&temp_units);\\n *\\n * if (rc != SAPI_STATUS_OK) {\\n * log_error(\\"ADC value out of range\\");\\n * SAPI_SAFESTATE(SAPI_SAFESTATE_LEVEL_SAFE, REASON);\\n * }\\n * // temp_units is now 0-4095 safely\\n *</tt>\n *\n * ### Example 2: CAN ID Conversion\n *\n * <tt>c\\n * uint32_t can_id = receive_can_id(); // CAN uses 29-bit or 11-bit IDs\\n *\\n * // CAN extended ID uses only 29 bits, 3 bits reserved\\n * if (can_id &gt; 0x1FFFFFFF) { // 29-bit max\\n * log_error(\\"Invalid CAN ID: 0x%x\\", can_id);\\n * return SAPI_STATUS_INVALID_PARAM;\\n * }\\n *</tt>\n *\n * ### Example 3: Pointer to Integer Conversion\n *\n * <tt>c\\n * // When storing pointers as integers (e.g., for debugging)\\n * void *ptr = get_pointer();\\n * uint32_t addr32;\\n *\\n * sapi_status_t rc = sapi_cast_ptr_to_uint32(ptr, \&addr32);\\n * if (rc != SAPI_STATUS_OK) {\\n * log_error(\\"Pointer too large for uint32_t\\");\\n * // On 64-bit system, address might not fit in 32 bits\\n * }\\n *</tt>\n *\n * @section guidelines Best Practices\n *\n * 1. <strong>Always Use Checked Casts for Downcasting</strong>\n * - Never (type)value for size reduction\n * - Always check with sapi_cast_*\n * - Handle errors, don't ignore them\n *\n * 2. <strong>Upcasting is Safe</strong>\n * - int8 → int32: safe (no loss)\n * - Can use direct cast if confident\n * - Or use cast functions for consistency\n *\n * 3. <strong>Handle Errors Appropriately</strong>\n * - For safety-critical: trigger safe-state\n * - For non-critical: log warning\n * - Always have error path\n *\n * 4. <strong>Document Assumptions</strong>\n * - Comment why cast is safe\n * - Document expected ranges\n * - Help future maintainers\n *\n * @section see_also See Also\n *\n * - @ref cast_architecture for internal design\n * - @ref types_user_guide for fixed-width types\n * - @ref status_user_guide for error handling\n *\n */
