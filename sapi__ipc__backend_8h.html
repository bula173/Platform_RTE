Detailed Description

OS-backend adaptation surface for the IPC service (ADR-005, ADR-021).

For platform integrators implementing a sapi_ipc_backend_t and calling sapi_ipc_register_backend() - NOT part of the consumer API (safeapi/ipc/sapi_ipc.h). A real application should never include this file; only the startup code that wires a concrete backend does.
