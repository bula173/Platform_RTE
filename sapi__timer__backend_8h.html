Detailed Description

OS-backend adaptation surface for the Timer service (ADR-005, ADR-021).

This header is for platform/RTOS integrators implementing a sapi_timer_backend_t and calling sapi_timer_register_backend() - it is NOT part of the API a consuming application uses to create/start/stop timers (that is safeapi/timer/sapi_timer.h). A real application should never need to include this file; only the one piece of startup code that wires a concrete backend into the framework should.
