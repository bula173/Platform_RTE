Detailed Description

Vital channel message with integrated CRC-64.

Wrapper structure for redundant channel messages that ensures data integrity across transmission.

Usage pattern:

  1. Sender: Wrap data with CRC, send wrapped message
  2. Receiver: Receive wrapped message, unwrap (verify CRC)
  3. On mismatch: Trigger safe-state
