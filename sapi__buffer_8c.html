const unsigned char *  bytes,
size_t  n 
)
static

Appends n raw bytes at buf's current length, advancing it. Shared by every sapi_buffer_write_*_le/be function.

Parameters
bufDestination buffer. Must not be NULL.
bytesRaw bytes to append. Must not be NULL.
nNumber of bytes to append.
Returns
SAPI_STATUS_OK on success; SAPI_STATUS_INVALID_PARAM if buf or bytes is NULL or buf fails its validity check; SAPI_STATUS_RESOURCE_EXHAUSTED if n bytes will not fit.
