135 * Endianness-safe multi-byte access (ADR-006 section 2.5). Byte order is
136 * always explicit at the call site (_le / _be suffix) - there is no
137 * default/"network order" variant. write_* functions append at buf's
138 * current length and advance it, like sapi_buffer_copy_in(); read_*
139 * functions take an explicit offset and do not mutate the buffer, like
